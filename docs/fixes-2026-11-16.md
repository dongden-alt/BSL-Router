- Combo editing: transactional saves, server-confirmed state, rename/reference migration, deletion cleanup, aliases containing spaces/symbols, and escaped labels/index-based copy actions.

- Routed stream continuity: distinguish thought-only output from delivered body/tool content, classify empty/filter responses, preserve chronological output, and test continuation/fallback behavior. Increase mapped Gemini output-token cap to 32768.
- Native gateway: safe model extraction, native inference/quota correlation, slash-resource/method preservation, and client disconnect handling.
- Desktop patcher: disk-full resilient storage writes/backups and log handling; persistent quota-saver settings and optional tool-followup offloading.
- Portability: optional ASAR paths through BSL_BLACKSAND_STUDIO_ASAR and BSL_BLACKSAND_CODE_ASAR; runtime-state override through BSL_STUDIO_RUNTIME_STATE_PATH. Optional real-ASAR test uses BSL_TEST_ORIGINAL_ASAR.
- Regression coverage for quota, combos, stream continuity, gateway behavior, and desktop patching.

## Separate local dependency

The native SSE/identity-encoding negotiation, phase-separated connection/upload/header deadlines, no replay after acknowledged upload, and failed-client cleanup are implemented in the Studio Setup runtime bridge, a separate repository with no configured remote. That implementation is not included in this Router publication. The optional native lifecycle tests require that sibling checkout and skip when absent.
